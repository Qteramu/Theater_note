# Theater Note
個人用の観劇スケジュール・ログ管理サイトの初期レイアウトです。

## 開き方
- `index.html` をブラウザで開いてください。
- PCでは左側サイドメニュー、幅760px以下の画面では下部ナビゲーションに切り替わります。

## ファイル構成
- `index.html` : トップページ
- `pages/` : Calendar / Performances / Theater Log / Settings
- `css/style.css` : 全ページ共通デザインとレスポンシブ設定
- `js/app.js` : 共通ナビゲーションなどの処理

## 現在の状態
これは共通デザインとページ構成を確認するための初期プロトタイプです。公演登録、データ保存、実際のカレンダー連携、ログ自動追加などはこれから実装します。


## 修正内容（ナビゲーション）
- スマホでは下部メニュー内の5項目が横一列に並ぶよう修正。
- トップページと `pages/` 配下のページで、階層に合った相対リンクを設定。

- スマホ下部ナビの外側コンテナをブロック化し、内側の5列グリッドが全幅を使うよう追加修正。


## デザイン調整
- 個人用ツールとして、ブランドタグラインとトップページの装飾的なウェルカム文言を削除。
- トップページの見出しを Welcome から Home に簡略化。


## 公演管理（今回追加）
- 手動フォームで公演情報と複数の日程を登録・編集・削除できます。
- JSON貼り付けで1件または複数件の公演をプレビューして取り込めます。
- 重複候補（同じ公演名・会場、または同じID）がある場合、上書き／別名追加／スキップを選べます。
- 手動編集・削除にも確認を表示します。
- データはこのブラウザの localStorage に保存されます。

### JSON形式
`title`, `venue`, `periodStart`, `periodEnd`, `themeColor`, `generalEvents`, `memo`, `dates` を使用します。
`dates` は `date`, `startTime`, `events`, `status`（planned / attended / undecided / absent）, `memo` を持つ配列です。
