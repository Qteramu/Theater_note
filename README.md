# Theater Note
個人用の観劇スケジュール・ログ管理サイトの初期レイアウトです。

## 開き方
- `index.html` をブラウザで開いてください。
- PCでは左側サイドメニュー、幅760px以下の画面では下部ナビゲーションに切り替わります。

## ファイル構成
- `index.html` : トップページ
- `pages/` : Calendar / Performances / Theater Log / Settings
- `css/style.css` : 全ページ共通デザインとレスポンシブ設定
- `js/app.js` : 共通ナビゲーションなどの処理

## 現在の状態
これは共通デザインとページ構成を確認するための初期プロトタイプです。公演登録、データ保存、実際のカレンダー連携、ログ自動追加などはこれから実装します。
